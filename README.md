**[NetWatch](https://github.com/Shadeleo/netwatch)** — Real-time network monitoring dashboard built with Python (FastAPI) + Node.js.

- 📡 Live packet capture & bandwidth analysis
- 🔍 Local device discovery via mDNS / NetBIOS / ARP + IEEE OUI (~30k entries)
- 🚨 Automated anomaly detection — port scans, DDoS patterns, unusual protocols
- 📊 WebSocket dashboard with live charts & alert stream
- 🗄️ SQLite storage, async backend, cross-platform (Windows / Linux / macOS)
